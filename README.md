Lantern Route is a night courier card duel played beneath a city moon, where two rival messengers race their lantern light along the same dark streets. Each round a Beacon suit is lit and matching it scores, while matching the last winning suit chains a bonus that keeps a hot streak burning. The round winner earns lanterns equal to their card's value and the loser spills oil, so every lead is fragile and every misplay costs fuel. Three specials shake up the route: Storm scatters the plan, the Lantern Keeper guards a flame, and Shortcut cuts a risky path ahead. First to 30 lanterns wins the night, or snuff out the rival's 20 oil and leave them in the dark.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out npx tsx main.ts
```

Then open out/game/index.html in desktop Chrome, or serve the out directory with any static HTTP server. No build step, no network.
